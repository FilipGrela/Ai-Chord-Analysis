# Interfejs Graficzny (UI) — AI Chord Analysis

Zaawansowana aplikacja okienkowa zbudowana z użyciem **PyQt6**, służąca jako interaktywny front-end dla modelu sztucznej inteligencji. Pozwala na bezproblemową wizualizację predykcji akordów synchronizowaną z odtwarzaniem plików audio (.mp3, .wav).

## Wymagania i Instalacja
Aby móc uruchomić interfejs graficzny, upewnij się, że doinstalowałeś biblioteki odpowiedzialne za okna i multimedia:

```bash
pip install PyQt6 PyQt6-Multimedia
```

Aby uruchomić aplikację z poziomu głównego folderu uruchom polecenie
```commandline
python -m frontend.MainWindow
```
