# PRZETWARZANIE SYGNAŁU (DIGITAL SIGNAL PROCESSING)
Moduł matematyczny projektu. Nie zawiera logiki uczenia maszynowego.

- spectrograms.py: Klasa 'AudioProcessor'. Implementuje ekstrakcję CQT (Constant-Q Transform), Spectral Whitening (balans energii) i usuwanie krótkotrwałych szumów (perkusja).
- plot.py: 'SpectrogramVisualizer'. Narzędzia do generowania wykresów z obsługą interaktywnych współrzędnych (pokazuje nutę i oktawę po najechaniu myszką).
